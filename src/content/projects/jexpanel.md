I started Jexpanel in 2021 as an alternative game panel to software like [Pterodactyl Panel](https://pterodactyl.io) and [PufferPanel](https://pufferpanel.io) with speed, performance and extra features at the forefront of design and implementation decisions. What started as a simple fork led to thousands of community members, hundreds of GitHub stars and many SMBs using Jexpanel in a production environment to sell IaaS products to prosumers.

Since the start, many versions have been published featuring new changes and bug fixes reported by GitHub users to make the software more stable and suitable to more and more people. Version 4 (latest) is the result of years of experience developing widely-used Docker container management panels across the globe, and features tight integrations with payment providers like Stripe to handle all billing functions within one interface - ease of use for admins and users alike.

RBAC, Security Keys, SSH fingerprints,  MFA and precise audit logging enabled as standard ensure the software is secure and complies with GDPR standards. Billing information is never stored on-site, and no analytics are collected during the use of the application. External dependencies are constantly updated and vetted to ensure they live up to the same level of security and reliability.
